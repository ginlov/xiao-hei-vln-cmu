# About this repository

This repository is the main entry point for Team Xiao Hei's participation in the VLN CMU Challenge: https://www.ai-meets-autonomy.com/cmu-vln-challenge.

# Working principles

- Always run Python scripts inside the `uv` virtual environment.
- If a virtual environment does not exist, create one using Python 3.12.
- After completing each task, write a short report in `docs/tasks/` named: "TASK [#task-number] - Task purpose.md", and add a row for it to the table in `docs/tasks/index.md`.
